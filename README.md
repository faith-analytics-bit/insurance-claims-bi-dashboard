# Insurance Claims Performance Dashboard (Looker Studio & Power BI)

🔗 **[View Interactive Live Dashboard](https://datastudio.google.com/reporting/ea9000d2-5a52-4879-b4e9-ea84482834ba)**

## 📌 Project Overview
Interactive executive dashboard tracking **850 insurance claims** with a cumulative payout value of **KES 19,650,000**. Designed to monitor claims distribution, payout velocity, and category-level risk KPIs.

## 📈 Key KPIs Tracked
- **Total Claims Volume:** 850 claims
- **Total Paid Claims Value:** KES 19,650,000
- **Category Breakdown & Monthly Trends:** Interactive filters for claim status, category share, and time-series payout analysis.
